# Glossaire — Pause

Vocabulaire du domaine. Une définition par terme ; les synonymes à éviter sont indiqués.

## Organisation

**Équipe**
Espace partagé qu'un utilisateur rejoint avec un code (ex. les collègues d'un même site). Contient des catégories.
_À éviter :_ « team », « organisation ».

**Catégorie**
Subdivision d'une équipe dont les membres prient ensemble (au départ : Hommes, Femmes ; le nombre n'est pas limité). Un membre ne voit que sa propre catégorie.

**Groupe**
Créneau de prière au sein d'une catégorie, nommé G1, G2… (10 au plus par défaut, limite réglable par l'admin de catégorie). Un membre choisit le groupe avec lequel il prie.
_À éviter :_ « équipe » pour désigner un groupe.

**Code d'accès**
Code saisi dans l'application pour rejoindre une équipe ; chaque code mène à une catégorie précise de cette équipe. Peut être régénéré ou expirer.
_À éviter :_ « code d'équipe ».

**Ville de l'équipe**
Ville dont les horaires de prière officiels s'appliquent aux membres de l'équipe.

**Code de transfert**
Code à usage unique, généré par un admin, qui permet à un membre de retrouver son compte sur un autre ordinateur.

## Prière en groupe

**Horaire du jour**
Heure fixée chaque jour par un admin pour un groupe et une prière donnés (ex. « Dhuhr, G1 : 12:26 »). Ne concerne que Dhuhr et Asr.

**Publication des horaires**
Acte par lequel un admin rend visibles les horaires du jour d'une prière pour sa catégorie. Seuls les groupes ayant un horaire publié ce jour-là peuvent être choisis.

**Choix de groupe**
Sélection, par un membre, du groupe avec lequel il prie une prière donnée d'un jour ouvré (lundi à vendredi). Ce n'est pas un vote : chacun choisit pour soi, et peut changer d'avis jusqu'à l'heure du groupe.

**Groupe habituel**
Groupe qu'un membre choisit d'office pour une prière ; il devient son choix de groupe dès la publication des horaires, sauf s'il en change.

**Jumu'a**
Le vendredi, dans une catégorie où elle est activée, la prière de Dhuhr est remplacée par un créneau unique de Jumu'a dont l'admin fixe l'heure ; il n'y a pas de choix de groupe pour cette prière. Les catégories où elle est désactivée gardent leurs groupes de Dhuhr.

**Rappel**
Alerte plein écran affichée par l'application avant une prière. L'horaire du jour du groupe choisi est prioritaire ; à défaut, l'heure de rappel réglée par l'utilisateur s'applique.

## Échanges

**Discussion**
Fil de messages d'une catégorie, où ses membres échangent et où apparaissent les publications des horaires. Les admins d'équipe ont aussi leur propre discussion.
_À éviter :_ « chat », « canal ».

**Annonce**
Message d'un admin mis en avant et notifié à tous les membres concernés.

**Mention**
Désignation d'un membre dans un message (@nom), qui lui est notifiée.

## Rôles

**Super admin**
Propriétaire de la plateforme : voit et contrôle toutes les équipes et tous les utilisateurs depuis le tableau de bord global.

**Admin d'équipe**
Gère une équipe : son code, ses catégories et ses membres.

**Admin de catégorie**
Gère une catégorie : ses groupes, leur limite et les horaires du jour.

**Responsable horaires**
Membre désigné par un admin qui peut seulement fixer les horaires du jour.

**Membre**
Utilisateur ayant rejoint une équipe ; choisit son groupe et participe à la discussion de sa catégorie.
